Abstract:
  The aim is to distinguish between nasal and oral vowels using five acoustic
  measurements of each vowel. The data comes from the ROARS project,
  which developed a real-time analytical speech recognition system for French and Spanish.

Data Characteristics:
  Vowels come from 1809 isolated syllables (for example: pa, ta, pan, ...).
  Three observation moments were kept for each vowel: the observation at maximum
  total energy (Ene), and the observations 8 msec before and 8 msec after it.
  This gave 5427 instances; 23 instances whose five first harmonics all had
  amplitude zero were removed, leaving 5404. Patterns are in random order.
  The attributes in the OpenML copy are standardized (mean 0, standard deviation 1).

Notes:
  The data was created by Dominique Van Cappel, THOMSON-SINTRA.
  AHi/Ene is the amplitude of harmonic i normalised by the total energy Ene
  (integrated over all frequencies). Each harmonic is signed: positive when it
  corresponds to a local maximum of the spectrum and negative otherwise.
  The original ELENA documentation codes the classes as 0 = nasal and 1 = oral;
  the OpenML file shows them as 1 and 2 (mapping inferred from the class sizes,
  3818 nasal and 1586 oral).

library(tidyverse)
DF1 <- read_csv("https://nmimoto.github.io/datasets/phoneme.csv")
DF1


# Define function that converts (1,2) to (No, Yes)
thisFunc01 = function(x) {
    case_when(x == 1 ~ "No",
              x == 2 ~ "Yes",
              .default = NA)}

# Apply the function
DF2 <- DF1 %>% mutate_at("Class", thisFunc01) %>%
    mutate_at("Class", as.factor) %>%
    mutate(Class = factor(Class, levels=c("No", "Yes")))

DF2
levels(DF2$Class)   # Important that the order is ("No", "Yes")
